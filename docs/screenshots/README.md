# Screenshots

These PNGs were captured from the actual SimFarm_V0 browser runtime in Chrome,
at a 1280 × 960 viewport (2× the native 640 × 480 canvas), on September 15, 2026.
They contain no generated artwork or composited UI.

- `title.png`: the opening SimFarm title screen.
- `farm.png`: the first authored scenario, showing fields and storage buildings.
- `map.png`: the live Overhead map over the same farm.
- `farm-expert.png`: the Farm Expert's field icon guide.

To reproduce the farm view, run the local server and open:

```text
/?scenario=0&window=main&dx=-2&dy=-1&dosclock=1993-07-17T12:34:56
```

Use the globe button to open Map. Close it, then choose Windows → Farm Expert.
Keep the pointer on the toolbar while capturing: moving it to a canvas edge
can scroll the farm.
